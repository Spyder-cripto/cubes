# CUBES — versión PuzzleScript Next

Recreación en **PuzzleScript Next** de *CUBES* (v0.19, «Work In Progress»), el juego de Scratch de **griffpatch**:
https://scratch.mit.edu/projects/948573479/

- Los 19 niveles y todos los dibujos (cubos, ladrillos, escaleras, ascensores, robot y fondos) son los del proyecto original de griffpatch.
- Las reglas se han traducido de su código de Scratch; aquí el juego va por casillas y los ascensores avanzan con el tiempo.
- Sonidos y música («Ping Pong», de pixabay.com, la que usa el original) también del proyecto de griffpatch; el robot está animado con sus fotogramas.
- Todos los niveles se han comprobado con solución.

Controles: flechas para andar, subir y bajar; **Arriba** junto a un bloque para trepar; **X** para empujar; **R** reinicia; **M** quita o pone la música.
Junta los cubos del mismo color: al tocarse desaparecen.

Créditos: juego, niveles y gráficos originales de griffpatch (Scratch, licencia CC BY-SA 2.0). Esta adaptación se comparte con la misma licencia.
